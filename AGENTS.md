# Repository instructions

For every task that changes this repository, run the relevant checks, commit the completed task changes, and push the working branch to `origin` before reporting completion. Set the upstream on the first push if needed. Verify the remote branch contains the commit. GitHub Pages publishes from `main`, so changes go live once they reach that branch.

Only commit files that belong to the task. Respect explicit instructions from the user about commits and pushes. If a required check or push fails, report the blocker and say which changes are still local.
