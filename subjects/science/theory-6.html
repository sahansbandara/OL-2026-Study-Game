⚗️ රසායනික ප්‍රතික්‍රියා, මවුල, අම්ල-භස්ම හා විද්‍යුත් රසායනය

මවුල ගණනය, ප්‍රතික්‍රියා සමීකරණ, ලෝහ ක්‍රියාශීලතා/විඛාදනය/කෝෂ, විද්‍යුත් විච්ඡේදනය, හයිඩ්‍රොකාබන හා පොලිමර. B කොටසේ රසායන ගණනයන් ලකුණු 20ක් දක්වා එනවා.

⚖️ මවුල සංකල්පය හා ගණනය 🔥 රසායනික ප්‍රතික්‍රියා, තාපය, ශීඝ්‍රතාව හා වායු 🧪 අම්ල, භස්ම හා pH 🔋 ලෝහ ක්‍රියාශීලතාව, කෝෂ හා විද්‍යුත් විච්ඡේදනය 🛢️ හයිඩ්‍රොකාබන, ඒවායේ ව්‍යුත්පන්න හා පොලිමර
ශ්‍රේණිය 10 · ප්‍රමාණනය (7.1–7.4) නිතර එයි

⚖️ මවුල සංකල්පය හා ගණනය

මවුලය = අංශු 6.02 × 10²³ ක් (ඇවගාඩ්‍රෝ නියතය L). සාපේක්ෂ පරමාණුක ස්කන්ධ (Ar): H 1, C 12, N 14, O 16, Na 23, Mg 24, S 32, Cl 35.5, Ca 40, Fe 56, Cu 64.

🔑 ප්‍රධාන සමීකරණ

n = m / Mn (mol), m (g), M (g mol⁻¹)M = Mr (අංකිකව සමාන)

🧮 1 — Fe₂O₃ → Fe (2024 Q6 ✔)

Fe₂O₃ හි Mr = 2×56 + 3×16 = 160; Fe අඩංගු = 112. Fe 70 t ලබා ගැනීමට Fe₂O₃ = 160/112 × 70 = 100 t.

🧮 2 — NaOH ද්‍රාවණයක්

0.1 mol dm⁻³ NaOH 250 cm³ ට අවශ්‍ය NaOH ස්කන්ධය: n = C×V = 0.1 × 0.250 = 0.025 mol; m = 0.025 × 40 = 1.0 g.

🧮 3 — ප්‍රතික්‍රියා ස්කන්ධ

Mg + 2HCl → MgCl₂ + H₂. Mg 2.4 g (0.1 mol) දෙන H₂ = 0.1 mol = 0.2 g. (මවුල අනුපාතය Mg : H₂ = 1 : 1)

  1. තුලිත සමීකරණය ලියන්න.
  2. දී ඇති ස්කන්ධය → මවුල (n = m/M).
  3. මවුල අනුපාතය භාවිතයෙන් සොයන ද්‍රව්‍යයේ මවුල.
  4. නැවත ස්කන්ධයට/සාන්ද්‍රණයට හරවන්න. ඒකකය අනිවාර්යයි.
⚠️

සුලභ වැරදි: V cm³ → dm³ බවට හරවන්න අමතක කිරීම (÷1000). Mr ගණනයේ අංක ගණිත දෝෂ. අවසාන පිළිතුරේ ඒකකය නොලීම (ලකුණු 01 නැති වේ).

🧪 ස්වයං පරීක්ෂාව: H₂SO₄ (Mr = 98) 9.8 g හි මවුල ගණන?

n = 9.8 / 98 = 0.1 mol.

🧪 ස්වයං පරීක්ෂාව: 2 mol dm⁻³ HCl 50 cm³ හි HCl මවුල ගණන?

n = 2 × (50/1000) = 0.1 mol.

✍️ ප්‍රශ්නය එන විදිහ: ගණනයට: තුලිත සමීකරණය (01) → ආදේශය (01) → අවසාන පිළිතුර + ඒකකය (01). 2024 Q6 (Fe₂O₃ ස්කන්ධය, Fe මවුල භාගය), 2021 Q6 (NaOH සාන්ද්‍රණය/මවුල), 2019 Q6 (500 cm³ ඇසිටික් අම්ල ද්‍රාවණය).

ශ්‍රේණිය 11 · රසායනික ප්‍රතික්‍රියා

🔥 රසායනික ප්‍රතික්‍රියා, තාපය, ශීඝ්‍රතාව හා වායු

රසායනික ප්‍රතික්‍රියා ඇඟවෙන ලක්ෂණ: වායුව පිටවීම, අවක්ෂේපය, වර්ණ වෙනස, තාප වෙනස්වීම.

වර්ගයසාමාන්‍ය ආකාරයඋදාහරණය
සංයෝජනA + B → AB2Mg + O₂ → 2MgO
වියෝජනAB → A + B2H₂O₂ → 2H₂O + O₂ (MnO₂ උත්ප්‍රේරකය)
විස්ථාපනA + BC → AC + BFe + CuSO₄ → FeSO₄ + Cu
උදාසීනීකරණඅම්ලය + භස්මය → ලවණය + ජලයHCl + NaOH → NaCl + H₂O

තාපදායක හා තාපාවශෝෂක

  • තාපදායක: තාපය පිට වේ (උෂ්ණත්වය ↑); උදා: Mg + HCl, උදාසීනීකරණය (2023 Q9 ✔), දහනය.
  • තාපාවශෝෂක: තාපය උරා ගනී (උෂ්ණත්වය ↓); උදා: සිට්‍රික් අම්ලය + NaHCO₃ (පෙළපොත).

ප්‍රතික්‍රියා ශීඝ්‍රතාව

  • ශීඝ්‍රතාව = පිට වූ වායු පරිමාව ÷ කාලය (cm³ s⁻¹) — උදා: H₂O₂ වියෝජනයේ O₂ ශීඝ්‍රතාව (2023 Q6).
  • වැඩි කරන සාධක: සාන්ද්‍රණය ↑, උෂ්ණත්වය ↑, පෘෂ්ඨ වර්ගඵලය ↑ (කුඩු කිරීම), උත්ප්‍රේරකය.
  • ප්‍රතික්‍රියාව ඇල්ලෙන විට ශීඝ්‍රතාව අඩු වේ — ප්‍රතික්‍රියක වැය වන නිසා (2023 Q6 ✔).
  • උත්ප්‍රේරකය: ශීඝ්‍රතාව වෙනස් කර තමා නොවෙනස්ව පවතී.

වායු හඳුනාගැනීම

O₂H₂O₂ + MnO₂දැල්වෙන ලී කූරක් දිලිසී පුළුස්සේ (දහනයට උපකාරී)
CO₂CaCO₃ + තනුක HClහුණු දියර කිරි පැහැ (CaCO₃ අවක්ෂේපය)
Cl₂MnO₂ + සාන්ද්‍ර HClතෙත් නිල් ලිට්මස් විරංජනය; කොළ-කහ වායුව
NH₃NH₄Cl + Ca(OH)₂තෙත් රතු ලිට්මස් නිල් වේ

🧪 ස්වයං පරීක්ෂාව: H₂O₂ ට MnO₂ එකතු කළ විට වායු පිට වේ. වායුව හා පරීක්ෂාව?

වායුව O₂; දැල්වෙන ලී කූරක් දැල්ල දීප්තිමත් වේ. MnO₂ = උත්ප්‍රේරකය.

🧪 ස්වයං පරීක්ෂාව: ප්‍රතික්‍රියාවක ශීඝ්‍රතාව කාලයත් සමඟ අඩු වන්නේ ඇයි?

ප්‍රතික්‍රියක සාන්ද්‍රණය අඩු වන නිසා (ප්‍රතික්‍රියක වැය වේ).

✍️ ප්‍රශ්නය එන විදිහ: “ප්‍රතිඵල ප්‍රස්තාරයෙන් ශීඝ්‍රතාව ගණනය කරන්න, සාධකයක් නම් කරන්න, වායුව හඳුනාගන්න” — 2023 Q6, 2018 Q3 (වායු තුනක් පිළියෙල වගුව), 2019 Q1 (H₂, O₂, CO₂ පිළියෙල), 2024 Q3 (X + HCl → H₂).

  • දර්ශක: ලිට්මස් (අම්ල රතු / භස්ම නිල්), ෆීනොප්තලීන් (භස්ම රෝස), මෙතිල් ඔරේන්ජ් (අම්ල රතු).
  • උදාසීනීකරණය: HCl + NaOH → NaCl + H₂O; අයනික සමීකරණය H⁺ + OH⁻ → H₂O (2023 Q9 ✔); තාපදායකයි — පොලිස්ටයිරීන් කෝප්පයක් තාප පරිවාරකයක් ලෙස.
  • NaOH භාවිත: සබන්, කඩදාසි නිෂ්පාදනය (2023 Q9 ✔).
  • ඔක්සයිඩ: CO₂, SO₂ ආම්ලික; Al₂O₃ උභයගුණී; MgO, CaO භාස්මික.

🧮 අනුමාපන ගණනය

0.1 mol dm⁻³ NaOH 25.0 cm³ උදාසීන කිරීමට HCl 20.0 cm³ ඕනේ නම් HCl සාන්ද්‍රණය?

ජලයේ භාගික අයනීකරණයක් පමණක් සිදු වන නිසා (2024 Q9 ✔; 2019 Q6 ඇසිටික් අම්ල ද්‍රාවණය).

සුලභ වැරදි: “ප්‍රබල අම්ලය = සාන්ද්‍ර අම්ලය” — එකක් නොවේ. ප්‍රබලත්වය = අයනීකරණ ප්‍රමාණය; සාන්ද්‍රණය = ද්‍රාවණයේ ප්‍රමාණය.

  • කැතෝඩ ප්‍රදේශය: O₂ + 2H₂O + 4e⁻ → 4OH⁻ — ෆීනොප්තලීන් රෝස (2023 Q6 ✔).
  • ආරක්ෂා කිරීම: තීන්ත ආලේපය, ගැල්වනයිස් (Zn), කැතෝඩීය ආරක්ෂාව (Zn/Mg කුට්ටි බැඳීම — යකඩට වඩා ක්‍රියාශීලී නිසා සිහියෙන් විඛාදනය වේ), මිශ්‍ර ලෝහ (වානේ).

සුලභ වැරදි: ඇනෝඩයේ ධන/සෘණ ලකුණ කෝෂයේත් විද්‍යුත් විච්ඡේදනයේත් ප්‍රතිවිරුද්ධයි. “ඇනෝඩය = ඔක්සිකරණය” දෙකටම සත්‍යයි.

විද්‍යුත් විච්ඡේදනය

  • විලීන NaCl (ඩවුන්ස් කෝෂය): කැතෝඩ — Na⁺ + e⁻ → Na; ඇනෝඩ — 2Cl⁻ → Cl₂ + 2e⁻. Na ක්‍රියාශීලී නිසා C සමඟ නිස්සාරණය කළ නොහැක ✔.
  • විලීන NaOH (හම්ප්‍රි ඩේවි): ඇනෝඩය 4OH⁻ → 2H₂O + O₂ + 4e⁻ ✔; කැතෝඩ Na⁺ + e⁻ → Na.
  • ලෝහාලේපනය: ආලේප කළ යුතු වස්තුව කැතෝඩය; ආලේපන ලෝහය ඇනෝඩය; ලෝහ අයන ද්‍රාවණය (CuSO₄ වැනි).

යකඩ නිස්සාරණය (ප්‍රවාහ උදුන)

  • C + O₂ → CO₂ ; CO₂ + C → 2CO
  • Fe₂O₃ + 3CO → 2Fe + 3CO₂
  • CaCO₃ → CaO + CO₂ ; CaO + SiO₂ → CaSiO₃ (ස්ලැග්) (යකඩ වාතයට ගැටීම වළක්වයි ✔).
  • අමුද්‍රව්‍ය කුඩු කිරීම → පෘෂ්ඨ වර්ගඵලය ↑ → ශීඝ්‍රතාව ↑ ✔. CO₂/CO නිසා ගෝලීය උණුසුම/විෂ ✔.

🧪 ස්වයං පරීක්ෂාව: Zn/Cu කෝෂයේ ඉලෙක්ට්‍රෝන ගලන්නේ කුමක සිට කුමකටද? ඇනෝඩය කුමක්ද?

බාහිර පරිපථයේ Zn සිට Cu දෙසට; ඇනෝඩය = Zn (ඔක්සිකරණය, සෘණ).

🧪 ස්වයං පරීක්ෂාව: යකඩ නළයකට Zn කුට්ටියක් සම්බන්ධ කිරීමෙන් සිදු වන්නේ?

කැතෝඩීය ආරක්ෂාව — Zn යකඩට වඩා ක්‍රියාශීලී නිසා Zn ඔක්සිකරණය වී (කැපී යන) යකඩ ආරක්ෂා වේ.

🧪 ස්වයං පරීක්ෂාව: Cu ආලේපනයේදී ඇනෝඩය හා කැතෝඩය?

ඇනෝඩය: Cu කුට්ටිය; කැතෝඩය: ආලේප කළ යුතු වස්තුව; ද්‍රාවණය CuSO₄.

  • LPG = ප්‍රොපේන් + බියුටේන් (ද්‍රවීකරණය කළ).
  • ඇල්කීන් බ්‍රෝමීන් ජලය විවර්ණ කරයි (අසංතෘප්ත පරීක්ෂාව); ඇල්කේන වලට ප්‍රතික්‍රියා නැත.
  • බොරතෙල් භාගික ආසවනයෙන් වෙන් කරයි (LPG, පෙට්‍රල්, භූමි තෙල්, ඩීසල්, බිටුමන්).
  • එතනෝල් (මද්‍යසාර) C₂H₅OH — ඇල්කොහොල් ක්‍රියාකාරී කාණ්ඩය –OH; ඇසිටික් අම්ලය CH₃COOH — දුබල අම්ලය.
  • එස්ටරීකරණය: ඇසිටික් අම්ලය + එතනෝල් ⇌ එතිල් ඇසිටේට් (එස්ටරය) + ජලය (2024 Q9 ✔: x = ජලය).

පොලිමර (addition)

  • n CH₂=CH₂ → ( –CH₂–CH₂– )ₙ — පොලිතීන් (PE). ඒකාවයවික ඇල්කීන; පොලිමරයේ දෙබන්ධනය නැත.
  • උදා: PE (ඉලිස්ටික් බෑග්), PP (බෝතල්/කාර්), PET (බෝතල්), PVC.
  • ස්වාභාවික රබර් = පොලිඅයිසොප්‍රීන් (ඒකාවයවිකය අයිසොප්‍රීන්) (2018 Q6, 2025 Q6 ✔).
  • ප්ලාස්ටික් නොදිරන නිසා දූෂණය; ප්‍රතිචක්‍රීකරණය/පොලිතීන් වැළකීම (2018 Q1 ✔).

🧪 ස්වයං පරීක්ෂාව: ඊතීන්වල මවුලික සූත්‍රය ලියා පොලිතීන් සෑදෙන සමීකරණය දක්වන්න.

C₂H₄; n CH₂=CH₂ → ( –CH₂–CH₂– )ₙ

🧪 ස්වයං පරීක්ෂාව: ඇල්කේන් හා ඇල්කීන් බ්‍රෝමීන් ජලයෙන් වෙන් කරන ක්‍රමය?

ඇල්කීන් බ්‍රෝමීන් ජලයේ දුඹුරු පැහැය විවර්ණ කරයි; ඇල්කේන නොකරයි.

✍️ ප්‍රශ්නය එන විදිහ: “P, Q, R පොලිමර හඳුනාගෙන ඒකාවයවික ලියන්න; ස්වාභාවික රබර් ඒකාවයවිකය; LPG සිලින්ඩර ගැන ප්‍රශ්න” (2018 Q6, 2021 Q6, 2025 Q6). ඒකාවයවික හා පොලිමර සූත්‍ර ලියන්න.
